# Wireless Network Configuration
## Overview

This section documents the wireless network configuration used in the Cisco Hybrid Enterprise Network Lab.

Wireless connectivity was provided through the WAP1-Corporate wireless access point, allowing laptops and mobile devices to connect to the on-premises network.

Wireless clients receive network addressing dynamically through DHCP.

## Wireless Infrastructure

| Device Name | Model | IPv4 Address | Subnet Mask | Purpose |
|---|---|---|---|---|
| WAP1-Corporate | Linksys WRT300N | 192.168.100.2 | 255.255.255.0 | Provides wireless connectivity for laptops and smartphones on the corporate network |
