# Cloud Connectivity
## Overview

This section documents the simulated cloud infrastructure used in the Cisco Hybrid Enterprise Network Lab.

The cloud environment extends the on-premises enterprise network by simulating external infrastructure and network services. A dedicated cloud router, cloud switch, and cloud server provide connectivity between the corporate office and remote resources, demonstrating a basic hybrid enterprise network architecture.

## Cloud Infrastructure

| Device Name | Device Type | Purpose |
|---|---|---|
| Cloud-PT | Cisco Cloud | Simulates WAN/ISP connectivity |
| Cloud Router | Cisco Router | Routes traffic between the cloud and on-premises network |
| Cloud Switch | Cisco Switch | Connects cloud-based devices |
| Email Server | Server | Provides email services for the enterprise |
| File Server | Server | Stores and shares files across the network |
| Application Server | Server | Hosts business applications for enterprise users |
