# Cisco-Hybrid-Enterprise-Network-Lab
Overview

This project is a simulated hybrid enterprise network built in Cisco Packet Tracer to develop and demonstrate practical networking and IT support skills. The lab combines an on-premises office network with a simulated cloud environment, providing hands-on experience configuring, managing, and troubleshooting common enterprise network services.

The environment includes routers, switches, wireless networking, desktop and mobile clients, and centralized network services such as DHCP and DNS. The project was designed to simulate the type of infrastructure an entry-level IT Support or Help Desk technician may encounter in a business environment.

Throughout the project, I configured IP addressing, routing, DHCP, DNS, wireless connectivity, and verified end-to-end communication between devices. I also documented and resolved connectivity issues encountered during implementation, including DHCP configuration, wireless client connectivity, routing, and network communication between the on-premises and cloud environments.

As the project continues to evolve, additional enterprise networking concepts such as VLAN segmentation, inter-VLAN communication, and enhanced network security will be incorporated to further simulate a real-world business network.
